# Olympic Games Data Analysis

## Project Overview
This project explores Olympic Games athlete and medal data using Python and Power BI. The goal is to analyse medal records by country, gender, year, sport, and medal category, and present the findings through an interactive dashboard.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Microsoft Power BI
- Jupyter Notebook / Google Colab

## Project Workflow
1. Loaded the Olympic athlete dataset and NOC region mapping data.
2. Merged the datasets using Pandas.
3. Explored and analysed medal records by country, gender, year, and medal type.
4. Created charts in Python to understand patterns in the data.
5. Built an interactive Power BI dashboard with KPI cards, charts, and slicers.

## Key Insights
- The United States recorded 5,637 medal records among the countries analysed.
- The dataset contained 28,530 male athlete medal records and 11,253 female athlete medal records.
- The selected year 2008 contained 2,048 medal records.
- The dashboard allows users to explore records by country/region, year, sport, and season.

*Note: These are athlete-event medal records, not counts of unique physical medals. Team events can contribute multiple athlete records for a single medal.*

The dataset is based on the Kaggle collection **120 Years of Olympic History: Athletes and Results**.

Dataset source: https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results

Download the CSV files from Kaggle before running the notebook. The notebook may require the CSV file paths to be adjusted to your environment.
